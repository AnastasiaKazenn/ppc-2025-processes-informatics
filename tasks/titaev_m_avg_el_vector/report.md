## 1. Введение
В данной работе реализуется параллельный алгоритм вычисления среднего арифметического значения элементов одномерного вектора (массива) с использованием технологии MPI. Цель — продемонстрировать способность распараллеливания линейной задачи **редукции** методом распределения данных между процессами и коллективных операций. Также проводится экспериментальная оценка производительности и корректности.

---

## 2. Постановка задачи
Дан вектор $V$ длины $N$, состоящий из целых чисел. Требуется определить среднее арифметическое значение его элементов.

Входные данные:
* Вектор $V$, состоящий из целых чисел произвольной длины (тип `std::vector<int>`).
* Выходные данные:
* Вещественное число $\bar{v}$ — среднее значение элементов вектора (тип `double`).

Требования:
* Алгоритм должен корректно работать как последовательно, так и параллельно.
* MPI-вариант должен давать одинаковый результат с последовательным методом и при любом числе процессов.
* Ограничения на размер входа отсутствуют; допускаются большие объемы данных.

---

## 3. Базовый алгоритм (последовательный)
Последовательный алгоритм имеет линейную сложность $O(N)$:
1. Инициализировать счетчик суммы `sum = 0` (тип `long long` для предотвращения переполнения).
2. Вычислить сумму элементов вектора: $\text{sum} = \sum_{i=0}^{N-1} V[i]$.
3. Разделить полученную сумму на количество элементов: $\bar{v} = \frac{\text{sum}}{N}$.
4. Вернуть итоговый результат.

Для реализации используется функция **`std::accumulate`** для эффективного суммирования.

---

## 4. Схема распараллеливания (MPI)

### Распределение данных:
* Процесс 0 (root) хранит исходный вектор целиком.
* Вектор $V$ делится на $P$ примерно равных блоков ($P$ — число процессов).
* С помощью коллективной операции **`MPI_Scatterv`** каждому процессу отправляется его подмассив.
* Каждый процесс считает **локальную сумму** элементов своего подмассива.

### Схема взаимодействия процессов (Глобальное суммирование):
* Локальный подсчет суммы внутри каждого процесса.
* Глобальное суммирование локальных сумм выполняется коллективной операцией **`MPI_Reduce`**.
    * $\sum_{\text{global}} = \text{Reduce}(\sum_{\text{local}}, \text{MPI\_SUM})$.
* Финальное деление на общее число элементов $N$ производится на **корневом процессе (Root)**, после чего результат записывается в `GetOutput()`.

### Псевдокод: 
* local_sum = sum(block) 
* global_sum = Reduce(local_sum, MPI_SUM) if (rank == 0): average = global_sum / N 
* GetOutput() = average

### Детали:
* Используется тип **`MPI_LONG_LONG`** для обмена суммами, чтобы гарантировать отсутствие переполнения.
* Операция `MPI_Bcast` используется для передачи общего размера вектора $N$ от процесса 0 всем остальным процессам.

## 5. Детали реализации

### Структура кода:
* **`common.hpp`:** Определяет входной тип `InType = std::vector<int>` и выходной тип `OutType = double`.
* **`ops_seq.cpp`:** Реализовано последовательное суммирование с помощью `std::accumulate`.
* **`ops_mpi.cpp`:** Реализовано распараллеливание с использованием `MPI_Scatterv` (распределение) и `MPI_Reduce` (сбор).
* **`main_func.cpp`:** Запускает функциональные тесты (проверка корректности) на небольших векторах.
* **`main_perf.cpp`:** Запускает тесты производительности на больших векторах.

### Важные моменты реализации:
* **Типы:** Для суммирования используется **`long long`**, а финальный результат приводится к **`double`**, что обеспечивает точность.
* **Распределение:** Расчет смещений (`displs`) и счетчиков (`send_counts`) для `MPI_Scatterv` учитывает возможную неравномерность деления, когда $N$ не делится на $P$ без остатка.
* **Генерация данных:** Тесты используют стандартные средства C++ (`std::random_device`, `std::mt19937`) для создания случайных векторов.

'int rank;'
  'int world_size;'
  'MPI_Comm_rank(MPI_COMM_WORLD, &rank);'
  'MPI_Comm_size(MPI_COMM_WORLD, &world_size);'

 ' unsigned int total_size = 0;'
  'if (rank == 0) {'
    'total_size = static_cast<unsigned int>(GetInput().size());'
  '}'

  'MPI_Bcast(&total_size, 1, MPI_UNSIGNED, 0, MPI_COMM_WORLD);'

  'if (total_size == 0) {'
      'GetOutput() = 0.0;'
      'return true;'
  '}'

  'std::vector<int> send_counts(world_size);'
  'std::vector<int> displs(world_size);'
  
  'int remainder = total_size % world_size;'
  'int base_count = total_size / world_size;'
  'int offset = 0;'

  'for (int i = 0; i < world_size; ++i) {'
    'send_counts[i] = base_count + (i < remainder ? 1 : 0);'
    'displs[i] = offset;'
    'offset += send_counts[i];'
  '}'

  'std::vector<int> local_vec(send_counts[rank]);'

  'if (rank == 0) {'
    'MPI_Scatterv(GetInput().data(), send_counts.data(), displs.data(), MPI_INT,'
                ' local_vec.data(), send_counts[rank], MPI_INT, 0, MPI_COMM_WORLD);'
  '} else {'
    'MPI_Scatterv(nullptr, send_counts.data(), displs.data(), MPI_INT,'
                ' local_vec.data(), send_counts[rank], MPI_INT, 0, MPI_COMM_WORLD);'
  '}'

  'long long local_sum = std::accumulate(local_vec.begin(), local_vec.end(), 0LL);'
  'long long global_sum = 0;'

  'MPI_Reduce(&local_sum, &global_sum, 1, MPI_LONG_LONG, MPI_SUM, 0, MPI_COMM_WORLD);'

  'if (rank == 0) {'
    'GetOutput() = static_cast<double>(global_sum) / total_size;'
  '}'

  'return true;'
